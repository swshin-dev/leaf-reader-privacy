GitHub Pages에 업로드할 파일은 `index.html` 하나입니다.

## 게시 전

1. 개발자 표시 이름은 `Leaf Developer`, 공개 문의 이메일은 `ssw5541@gmail.com`으로 반영되어 있습니다.
2. Play Console에도 같은 개발자 표시 이름과 문의 이메일을 설정합니다. 본인 인증용 법적 이름은 실제 이름을 사용합니다.
3. 날짜와 내용이 실제 앱 및 AdMob 계정 설정과 일치하는지 확인합니다.

영어와 한국어 내용은 같은 앱 동작을 설명합니다. 앱 파일은 기기에 보관하지만
Google 광고 SDK의 정보 수집·공유까지 없는 것으로 설명하지 않습니다.

## 무료 GitHub Pages 공개

1. GitHub에서 공개 저장소 `leaf-reader-privacy`를 새로 만듭니다.
2. 저장소 최상위에 이 폴더의 `index.html`만 업로드합니다.
3. Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Pages 화면에 표시된 HTTPS 페이지 주소를 로그인하지 않은 브라우저에서 확인합니다.
5. 그 주소를 Play Console 개인정보처리방침 URL에 입력합니다.

예시 형식: `https://YOUR_GITHUB_USERNAME.github.io/leaf-reader-privacy/`.
GitHub 저장소 화면 주소나 내 PC의 파일 경로를 입력하는 것이 아닙니다.
이 작업은 로컬 파일 작성까지만 완료한 것이며, 공개 URL은 아직 생성되지 않았습니다.
프로젝트 전체, signing 폴더, 업로드 키나 비밀번호 파일을 이 저장소에 올리지 마세요.

앱 내부에 현재 간단한 개인정보 안내가 있습니다. 공개 페이지 URL이 정해지면
앱에서도 전체 방침을 쉽게 열 수 있도록 링크를 추가할 수 있습니다.

https://developers.google.com/admob/android/privacy/play-data-disclosure
